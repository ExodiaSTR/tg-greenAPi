# QA — 02.10.2026

Вердикт: **partial-unverified**. Локальные автоматические проверки проходят; живой Telegram end-to-end не подтверждён.

Основной исполнитель: сверка PDF и официальных Telegram API-контрактов, TypeScript/production build, 12 Vitest-проверок (8 API/доменных, 4 компонентных). Проверены телефонный адрес и числовой chatId, дубликаты, текст/URL, неверные контракты и timestamp, запрос отправки, отказ без автоматического повтора/утечки токена, envelope/ACK, полный сценарий с имитацией, сохранение черновика, ошибки до выбора чата, выход во время создания чата. Реальный браузер: осмотр формы входа, подписи полей и отображение на 1280×720.

Независимый QA-агент прочитал исходники, проверил primary GetContactInfo/ReceiveNotification, самостоятельно запустил тесты и build. Его замечания исправлены:

1. Старый запрос контакта мог записать состояние после выхода: захвачен сигнал конкретной сессии; регрессия покрыта компонентным тестом.
2. Abort-обработчики задержки polling накапливались: обработчик удаляется после таймера/отмены.
3. Ошибка создания чата скрывалась на мобильном экране: вынесена из скрываемой conversation на уровень app.
4. Ошибка polling до выбора чата не была видима: состояние и кнопка повтора доступны в sidebar.
5. Некорректный timestamp мог обрушить Date-render: проверяется допустимая Date до обработки уведомления; добавлена регрессия.

Финальная независимая перепроверка: все пять замечаний закрыты; 12/12 тестов, TypeScript и production build прошли. Независимый браузерный просмотр не состоялся из-за недоступности браузера в сессии QA.

Ограничения: имитация API не проверяет CORS, права/тариф, авторизацию настоящего инстанса, реальные статусы, приватность номера и доставку в Telegram. Независимый агент не проверял авторизованный интерфейс в браузере. Мобильный CSS проверен по исходникам; реальные устройства/скринридер/полный accessibility-аудит не проверены. Исходные editable-макет/токены отсутствуют; точное соответствие MAX/Telegram не заявляется.

Ручная проверка для окончательного pass: README, два тестовых Telegram-аккаунта, настоящий вход, создание чата, отправка/ответ, отключение сети/восстановление, ошибка токена, два чата с отдельными черновиками, узкий экран и клавиатура. Историю после перезагрузки приложение намеренно не сохраняет; проверить предупреждение о границах хранения в инструкции.
